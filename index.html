Dónde se guardan tus evaluaciones

Los registros se almacenan en localStorage del navegador. Cerrar normalmente la pestaña no los borra, pero sí puedes perderlos al limpiar datos del sitio, usar navegación privada, cambiar de navegador/dispositivo o por políticas del navegador. Descarga periódicamente Excel o JSON. El JSON sirve para restaurar exactamente el estado de esta herramienta.

Catálogos centralizados en Supabase

La aplicación ya no depende de Firebase. El navegador consulta únicamente catalogos_riesgo_publicos(); la tabla base no tiene lectura ni escritura directa para anon o authenticated. Para cambiar los catálogos se utiliza una operación administrativa controlada.

Administración técnica

El botón Administrar catálogos abre catalogos-admin.html en esta misma pestaña. El panel exige credenciales de un administrador general y permite crear, editar, ordenar, activar o desactivar registros sin modificar SQL.
